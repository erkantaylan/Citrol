# Citrol

A small Discord-like web chat, built live in class. One server, text channels, login with Discord.

Stack: TypeScript on Bun, PostgreSQL, Docker Compose, deployed with Coolify.

## Discord app

1. Create an application at https://discord.com/developers/applications.
2. Under **OAuth2**, copy the client ID and secret.
3. Under **OAuth2 → Redirects**, add `<PUBLIC_URL>/auth/discord/callback`, one for each environment (for example `http://localhost:7421/auth/discord/callback`).

## Run locally

Put the values in `.env` (never commit it):

```
PORT=7421
PUBLIC_URL=http://localhost:7421
POSTGRES_USER=citrol
POSTGRES_PASSWORD=citrol
POSTGRES_DB=citrol
DATABASE_URL=postgres://citrol:citrol@localhost:7432/citrol
DISCORD_CLIENT_ID=
DISCORD_CLIENT_SECRET=
DISCORD_GUILD_ID=
```

Then either run everything in Docker:

```
docker compose up --build
```

or only the database in Docker and the app with live reload:

```
bun install
docker compose up -d postgres
bun run dev
```

Open http://localhost:7421.

`DISCORD_GUILD_ID` is optional. When it is set, only members of that Discord server can log in.

## Deploy on Coolify

1. New resource → this Git repository → build pack **Docker Compose**.
2. Set **Docker Compose Location** to `/docker-compose.coolify.yml`.
3. On the `app` service, set the domain with the container port, for example `https://citrol.example.com:7421`.
4. In the environment variables, set `PUBLIC_URL` (the same https domain, without the port), `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, and optionally `DISCORD_GUILD_ID`.
5. Add `<PUBLIC_URL>/auth/discord/callback` as a redirect in the Discord app.
6. Deploy.

The database password is generated by Coolify. Users and sessions live in the `citrol-db` volume, which survives redeploys, so people stay logged in across updates. Don't rename the `postgres` service or the volume: that starts an empty database.

## Database changes

Migrations are plain SQL files in `migrations/`, applied in name order when the app starts. Only add new files: never edit or delete one that has already run.
